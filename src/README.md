## Descripción
Aplicación en **Python** que gestiona turnos médicos usando **colas dinámicas (FIFO)**, una **interfaz gráfica con Tkinter**, y **visualización de la cola en Graphviz**.

---

##  Requisitos
- Python 3.10+
- Tkinter
- Graphviz

## Instalar dependencias:
```bash
pip install -r requirements.txt
```
🚀 Ejecución
python src/main.py
